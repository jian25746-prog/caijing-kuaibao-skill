# STEP 3 旁白脚本规则（完整自含，subagent 只读此文件）

## 素材使用铁律

先按 `news_id` 连接 selected_10 与 verification_table，**禁止按数组位置连接**。只处理 `publication_status:"ready"` 的条目；`blocked/conflict/rejected` 不得写入脚本。

核心事实层（主体/事件/范围/具体数字）只能取自 verification_table 的 `source_excerpt + verified_facts + list_items`。selected_10 的标题仅用于识别选题，不是标题以外的事实证据。背景因果、市场传导可基于财经常识推演，但必须使用“这意味着/可能/如果”等分析语气，不得伪造成已发生事实。

**🔴 国内源以 STEP2 事实包为准：** 国内源的事件性质与适用范围必须来自 `verified_facts`；任何被正文修正的原标题说法都会进入 `forbidden_facts`，禁止沿用或据其推演。

**信源引用规则：** `evidence` 中出现具体媒体名称时，正文直接具名引用（如“据《金融时报》报道”），禁止替换为“消息显示/市场关注到”等泛称。合规规则禁止的是无媒体名的泛称；具名“据《媒体》报道”允许使用。

**具名实体强制落地：** `verified_facts` 含具体股票代码/公司名/人名/产品名时，旁白必须念出这些名称，禁止泛化替代。

**列表型标题强制展开：** 标题含「X只/X件/X大/top X/these X」等数字列表结构时，必须逐一使用 verification_table 的 `list_items`；STEP2 已阻断列表不全的条目，不得从标题猜名单。

**数字白名单：** 只能使用 verification_table `allowed_numbers` 中逐字列出的数字及单位。`uncertain_facts/forbidden_facts` 中的数字即使加“约”字也不得使用；需要表达争议时只说“不同来源口径不一”，不复述被禁数字。

**根据实出条数调整（N条）**：全篇按**有效条数 N**执行（N 可少于10）：开场白结尾"十件大事"改说"N件大事"（如9条→"九件大事"）、正文写 N 条、"N条用N种句型开头"。

**数据纪律：**

- **时点纪律**：先读 market_snapshot.json 的 `session`。仅 `session:"closed"` 可称收盘价；冬令时4am若为 `session:"regular_live_15:00ET"/status:"preclose"`，只能说“截至美东15时”或完全省略数字，严禁称收盘。
- **收盘数字全篇唯一**：三大指数收盘数字全篇只出现一次——N条中有行情综述类条目则放该条正文，否则放今日前瞻。禁止正文与前瞻双口径。
- **数字三要素与锚**：数字尽量带口径+时间窗+参照系；事实包给不出口径或锚时砍掉数字保留事件，并在 summary 列出。正文禁止出现任何“待核实”占位文字。
- **数字密度上限**：单条连续数字 ≤4 个，超出 → 保留最重要 3 个 + 归并句（"其余品种涨幅多在1.5%以内"）
- **罕见指标拦截（幻觉高发区）**：实际收益率、盘前永续合约、隐含波动率等非常规指标，只有进入 `verified_facts` 且数字列入 `allowed_numbers` 才可出现；否则直接删除。

## 脚本结构（四段）

### ① 开场白

```
各位好，这里是《{SHOW_NAME}》，本期覆盖北京时间[时间范围]的全球财经大事。[今日动态引入] 八分钟，十件大事一次讲完。
```

- **[时间范围]**：取 verification_table 最早一条发布时间，取整到小时，按其 MM-DD 与今日对比分支：
  - 最早条是**昨日** → "昨日[X]时至今日四时"（如"昨日二十时至今日四时"）
  - 最早条是**今日凌晨（00–04时）** → "今日凌晨[X]时至四时"（如"今日凌晨零时至四时"），**此时禁止写"昨日"**
- **今日动态引入**：结果先行，一句话点出今日核心信号（如"昨晚一份就业数据把收益率点燃了，科技股、比特币、大宗商品被同一只手按了下去"）；禁止戏剧化揭晓式（"你知道谁是今晚最可怕的人吗？"）
- **定调句只写当日事件**：趋势性内容（"黄金阴跌四个月"）不得包装成当日动作（"黄金没能扛住今天的数据"）；当日确无大事可定调时，取窗口内最大单一事件

---

### ② 正文 N 条新闻

**每条格式：**
```
第X条 [标题]。[正文] [影响段]
```

**正文规则：**
1. **禁止重复标题主谓**：标题已说明的事实，正文不得重复同一主语+谓语。标题是结论，正文从标题未涉及的细节切入：具体数字、原因或新角度
2. **每条独立成篇**：禁止引用或预告其他条（不说"如第X条所说"/"正如前面提到的"）；同一底层事件（如非农数据）可在各条内独立陈述，不算跨条引用
3. **N条用N种不同句型开头**，禁止重复

**影响段规则（2-3句，当条说透）：**
1. 具体到人群场景，不泛称"普通投资者"，说"手里有XX的人"
2. 有因果推导，不直接抛结论，先说"因为X，所以Y"
3. 禁止以空洞动词收尾："留意/审视/做好准备"必须接具体内容，无内容直接删
4. 金融术语翻译为人话：
   - "盈利预期下修" → "公司挣的可能比预期少，股价有压力"
   - "逻辑支撑" → 说清楚对哪类人有什么具体用处
   - "系统性逆风" → "全球都在跌，国内板块也躲不开"
   - "估值承压" → "这类资产价格有下行压力"
5. **比喻分好坏**（判定见 style_dna.md）：✅ 一秒就懂、有画面的好比喻鼓励用（如「海峡堵多久，加油站的油就贵多久」）；❌ 要脑补的分析师比喻删掉（两个时钟、暗线、压舱/冲锋、潮水退去）
6. **落点句式轮换**：N条影响段的收尾句式至少 `min(3,N)` 种轮换（提醒式/反问式/行动式），禁止连用"对……的朋友/投资者"同一模板

---

### ③ 今日前瞻（要真预判，不复述正文）

> 数据源：读 `market_snapshot.json`。仅 `session:"closed"` 可使用三大指数收盘点位；`status:"preclose"` 时按“截至美东15时”处理或省略数字，`failed` 时只写事件前瞻。禁止“以行情为准”搪塞。

写三层，每层都要"前瞻"而非复述正文已讲的事：
1. **行情定调**：收盘数字若已在正文条目报过 → 此处只说方向与多空含义，**禁止复述数字**；正文未报 → 在此报三大指数收盘点位+涨跌幅（全篇唯一一次）
2. **关键事件情景推演**（核心）：今日/明日最重要的 1-2 个事件，做"如果 X → 那么 Y"的双向推演（如"CPI 若高于预期，降息预期进一步推迟、成长股承压；若低于，则风险偏好回暖"）——必须有方向判断，这是前瞻的灵魂
3. **尾部风险**：1-2 个，说清"触发条件 + 影响路径"，不只是把正文已说的事再念一遍

❌ 把正文已讲事实当前瞻复述一遍；❌ "以行情为准"搪塞

---

### ④ 结尾

```
[今日一句话总结：一句话点出今日核心结论或给听众的行动启示] 感谢收看，觉得有用的话点个赞、关注一下，明天早上七点，我们准时见。
```

> ⛔ **免责声明"所有评分仅供参考，不构成任何投资建议，市场有风险，投资须谨慎"从旁白永久删除**，由 PNG 切片底部视觉层承载，不在脚本中出现。

## 语言规范

### 风格基调（写稿前必读 style_dna.md）

先读风格圣经：`{SKILL_DIR}/prompts/rules/style_dna.md`

快报正文取**轻度浓度**——在「说人话、不绕」的基础上吸收范文的人味，但每条仅约200字、节奏要快，不展开成段子：
- 偶尔一个**一秒就懂的好比喻**点睛即可，不强求每条都有
- 适度的态度与共情，敢说「这事儿得当心」，但不堆梗
- **大数字落到可感坐标**（换算成「几个月工资」），别干巴巴罗列
- 把宏观落到「手里有XX的人」

> 🔥 放开用梗与段子比喻的「浓郁版」留给 90秒解读 / 一周回顾；快报正文克制。

### 文本形态（纯文字稿，不再录制音频）

- **禁止任何录音标记**：不加 `<#1#>`/`<#0.5#>` 停顿符，不写"清嗓声"等录音指令
- **数据数字一律阿拉伯形态**：点位/涨跌幅/金额/利率/基点（4.2%、7266.99点、23亿美元、2.4个基点）
- **序号与习语数词保留中文**：第一条、十件大事、八分钟、明天早上七点

### 禁止 AI 腔词（遇到即替换）

| 禁止 | 替换方向 |
|------|----------|
| 叠加 | 再加上 / 碰上 |
| 与此同时 | 直接说结果 |
| 值得注意的是 | 直接说 |
| 外溢影响 | 传到了XX / 烧到了XX身上 |
| 同步调整 | 也跌了 / 也涨了 |
| 呈现X态势 | 直接说往上走 / 往下跌 |
| 不得不关注 | 直接说 |

- "市场关注到" 全篇最多用 2 次
- "数据显示" 全篇最多用 2 次

### 禁止写法

- **戏剧化揭晓钩子**："你知道谁是今晚最可怕的人吗？" → 改为结果先行
- **坏比喻**：要脑补才懂的分析师比喻（两个时钟、暗线、压舱/冲锋）删除；✅ 一秒懂、有画面的好比喻鼓励用（判定见 style_dna.md）
- **空洞动词收尾**：留意/审视/做好准备 → 必须接具体内容
- **结论直抛**：先有推导，结论自然出来
- **金融分析师语言**：盈利预期下修、逻辑支撑、系统性逆风 → 翻译成人话

## 三阶段写作流程

### 第一阶段：结构规划（Write → script_outline.txt）

- N 条播报顺序：前 `min(3,N)` 条优先放**选题分最高**者（2026-09-08：原「或 weighted≥8」已删——强热点特权在 STEP1 已废除，此处保留会让白名单效应换个地方继续）；中间全球宏观→国内市场→行业个股；结尾情绪偏正向。结构表每条必须携带 `news_id`，后续重排只改播报序号，不改 news_id。
- **主线自洽检查**：明确今日"降息预期/美元/利率"三个方向，N条与前瞻必须同向；素材确有冲突则显式写"此前 vs 现在"，禁止两条各说各话
- 收盘数字落点决策：放哪条正文 or 今日前瞻（全篇唯一）
- 今日动态引入用哪个核心信号？
- 今日前瞻核心：行情定调 + 1-2 个关键事件的"如果X→那么Y"预判 + 尾部风险

### 第二阶段：正文写作

按脚本结构四段完成全文：N=10时目标约2200-2800字；N<10时每少1条同步减少约180-220字（估算即可，允许±400误差），禁止为凑固定总字数扩写事实。

### 第三阶段：自检与落盘

> ⛔ **严禁字数微调循环**：bash 字数验证只能在最终落盘后跑一次；超出范围在 summary 如实报告，不重写。

完成以下 9 项检查，**仅凭内部判断**，有明显不通过则修改一次后落盘：
- □ 开场白时效声明日期分支正确（最早条是今日凌晨时未写"昨日"），定调句只写当日事件
- □ 每条正文未重复标题主谓
- □ 每条影响段具体到人群，无空洞动词收尾，落点句式≥`min(3,N)`种轮换
- □ 无跨条引用（"如第X条所说"等）
- □ 结尾无免责声明文字
- □ 今日前瞻：行情定调与收盘数字落点一致（数字未在前瞻与正文重复出现）、有"如果X→那么Y"预判、未复述正文
- □ 通篇扫禁词与泛称信源：禁词表（与此同时/叠加/值得注意的是等）清零；"消息显示/市场消息显示/据披露的数据"已替换为具体媒体名；外媒时段词已换算北京时间且全篇一致
- □ 主线自洽：降息/美元/利率方向全篇一致，冲突处已写"此前 vs 现在"
- □ 数据纪律与文本形态：所有事实数字均在对应 news_id 的 allowed_numbers 中；forbidden_facts 未出现；收盘/盘中标签正确；单条连续数字≤4；无停顿符/清嗓声/占位文字

全部通过后**一次性** Write 工具写入输出文件，不再修改。
