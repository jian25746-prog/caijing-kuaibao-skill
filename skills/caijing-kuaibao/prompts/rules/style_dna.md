# 凡人财经 · 文案风格圣经（style_dna）

> 全项目口播/文字稿的统一风格基准。7点快报正文（step3_rules）、日更三件（derivatives）、一周回顾（weekly-review）**共同遵守**。
> 依据：用户认可的三篇范文——SK海力士「人均奖金610万」/ 硅基对碳基 / 霍尔木兹电诈。共同点是「没有新闻腔、口语、播报顺畅」。

---

## 一、风格七条 DNA

1. **开头 = 反差或结果先行**，不卖关子、不揭晓式悬念
   - ✅「硅基对碳基的绞杀，已经到了令人窒息的程度」
   - ✅「没想到电诈的风，竟然吹到了霍尔木兹海峡」
   - ❌「你知道昨晚谁最可怕吗？」（揭晓式，禁用）

2. **比喻要「一秒就懂、有画面」**（判定见第二节，全项目最重要）

3. **有态度、敢吐槽、会共情**
   - 「说实话，我看了都眼红」「这玩意你跟谁说理去」「现实比电影还魔幻」

4. **设问 + 互动，把人拉进来**
   - 「你以为这就完了吗？错！」「大家觉得呢？」「你说姑娘能不喜欢吗？」

5. **网络梗 / 谐音 / 化用成语**，适度自然、不堆砌
   - 「厚礼蟹」「要站在光里，别光站着」「和光同尘、与碳为伍」「跌成翔」

6. **大数字落到可感坐标**，不干巴巴罗列
   - 「1.4亿韩元 ≈ 65万人民币 ≈ 29.6个月工资」「三年奖金加工资，接近1000万」

7. **宏观永远落到「普通人的命运」**
   - 内存暴利 → 相亲/结婚/阶层跨越；AI抱团 → 散户一周赚一年 vs 反弹麻醉自己

---

## 二、好比喻 vs 坏比喻（全项目最重要的判定）

> **判定标准**：一个没学过金融的人，第一遍听到，会不会立刻懂、会不会有画面？
> 会 → 好比喻，**鼓励用**；要停下来想「这是什么意思」 → 坏比喻，**删**。

| ✅ 好比喻（一秒懂、有画面、带情绪） | ❌ 坏比喻（要脑补、装深刻、分析师腔） |
|---|---|
| 玩鹰的，被鹰啄瞎了眼 | 长期和短期是两个时钟 |
| 海力士工服 = 相亲最强战袍 | 一条暗线 / 明线 |
| 硅基夺舍了碳基 | 压舱石 / 冲锋号 |
| 海峡堵多久，加油站的油就贵多久 | 潮水退去才知道谁在裸泳 |
| 钱被骗、船没出去、还挨了揍，一炮三响 | 估值的地基 / 情绪的门 |

## 三、风格浓度分级（按产物区分用量）

| 产物 | 浓度 | 怎么用 |
|---|---|---|
| **90秒解读 / 一周回顾** | 🔥 浓郁 | 出镜攒人格，放开用：态度 + 段子比喻 + 设问 + 适度梗，最贴近三篇范文 |
| **7点快报正文（10条）** | 轻度 | 每条约200字、要快——说人话 + 偶尔1个好比喻点睛，不强求每条有梗、不展开成段子 |
| **30秒名词** | 类比版 | 一个生动的生活类比讲透一个词，梗克制、保清晰 |
| **头条图文** | 钩子版 | 标题可带梗钩子，正文以民生清晰为主 |

## 四、不可逾越（所有浓度通用，继承各 stepN_rules 禁忌）

- **禁 AI 腔词**：叠加 / 与此同时 / 值得注意的是 / 外溢影响 / 同步调整 / 呈现X态势 / 不得不关注
- **禁空洞动词收尾**：留意 / 审视 / 做好准备 → 必须接具体内容，没有就删
- **禁金融黑话**：盈利预期下修→挣的比预期少；估值承压→价格有下行压力；系统性逆风→全球都在跌躲不开
- **禁全局违禁词**：震惊 / 重磅 / 惊曝 / 历史性 / 必涨 / 必跌 / 稳赚 / 绝对 + 任何确定性断言
- **数字三档**：✅核实直接用 / ⚠️无印证加「约」 / ❌冲突写范围；禁「以行情为准」搪塞
- **信源直引**：FT/Reuters/Bloomberg/CNBC 等具名媒体直接引用，禁「消息显示」泛称
- **具名实体强制落地**：公司名/代码/人名必须念出，禁「某公司」「三只分红股」泛化
- **梗的红线**：暂沿用 compliance.md 平台合规底线（政治敏感 / 低俗不碰）

## 五、时间表达铁律（全产物通用）

1. 稿件内所有时间一律**北京时间**，禁止直译外媒时段词（morning / afternoon / tonight / Wednesday / ET 等）——血案：CPI 的美东 "Wednesday morning" 被直译成"今天上午"，实际是北京时间当晚 20:30。
2. 换算：美东时间 +12 小时 = 北京时间（3-11月夏令时 EDT；冬令时 EST 则 +13）。速查：
   - 美东 8:30AM 数据（CPI / 非农 / PPI / 初请失业金）= 北京**当晚 20:30**
   - 美股开盘 9:30AM = 北京 21:30；收盘 4:00PM = 北京次日凌晨 4:00
3. 同一事件的时间，同一篇稿内前后必须一致（不许正文说"今天上午"、前瞻说"今晚八点半"）。
4. 拿不准具体时点 → 写"今天晚些时候 / 今晚"，绝不直译外媒时段词。
