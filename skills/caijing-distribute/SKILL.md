# 节目分发（YouTube / 视频号 / 今日头条 自动 · 小红书手动包）

- **触发**：用户说「分发 <节目> <日期>」（如 `分发 7点财经快报 9月25日`），手动触发。
- **输入**：`caijing-kuaibao` 与 `caijing-broll-compose` 当天产出的成片（`成片/成片_XX_主题.mp4` 或 `第X条.mp4`）、`今日播报内容.txt`、`首条评论.txt`。
- **只读节目目录，绝不写入**；所有账号登录态、密钥、发布物料都放在仓库之外的 `{UPLOAD_HOME}`。

════════════════════════════════════
【运行配置】
════════════════════════════════════

| 占位符 | 含义 | 解析方式 |
|---|---|---|
| `{SKILL_DIR}` | 本 SKILL.md 所在目录，脚本在 `{SKILL_DIR}/src/` | Claude Code 加载本 skill 时告知的基础目录；插件安装时为 `${CLAUDE_PLUGIN_ROOT}/skills/caijing-distribute` |
| `{UPLOAD_HOME}` | 账号登录态、YouTube 密钥、`config/shows.json`、`物料/` 所在目录 | 环境变量 `CAIJING_UPLOAD_HOME`；未设置时默认 `~/caijing-distribute` |

```
{UPLOAD_HOME}/
├── config/
│   ├── shows.json                  从 {SKILL_DIR}/config/shows.example.json 复制后修改
│   ├── youtube_client_secret.json  Google Cloud 下载的 OAuth 客户端密钥
│   ├── youtube_token.json          首次授权后自动生成
│   ├── sph_profile/                视频号登录态（扫码后自动生成）
│   └── tt_profile/                 今日头条登录态（扫码后自动生成）
└── 物料/<节目>/<日期>/              每日解析结果、发布物料、封面、小红书手动包
```

> 🔐 `{UPLOAD_HOME}/config/` 里的文件等同于你的账号本身，**永远不要提交到任何 git 仓库或发给别人**。

════════════════════════════════════
【一次性准备】（登录态过期才重做，约数周一次）
════════════════════════════════════

- **YouTube**：在 Google Cloud 开通 YouTube Data API v3，建 OAuth 客户端（桌面应用），下载的 JSON 放到 `{UPLOAD_HOME}/config/youtube_client_secret.json`；首次运行上传脚本会弹浏览器授权，之后 token 自动刷新。
- **视频号**：`python3 "{SKILL_DIR}/src/sph_open.py"` → 微信扫码 → 登录态存入 `config/sph_profile`。
- **今日头条**：`python3 "{SKILL_DIR}/src/tt_open.py"` → 扫码 → 登录态存入 `config/tt_profile`。
- **小红书**：不需要登录，本工具只生成手动发布包。
- 扫码登录是身份认证动作，由用户本人完成。

════════════════════════════════════
【日常分发】（用户说「分发 <节目> <日期>」时执行）
════════════════════════════════════

**STEP 1 解析当日产物**
```bash
python3 "{SKILL_DIR}/src/parse_products.py" <节目> <日期>
```
→ `{UPLOAD_HOME}/物料/<节目>/<日期>/clips_raw.json`

**STEP 2 写发布文案（模型）**
读 `clips_raw.json` + `{SKILL_DIR}/prompts/title_style.md` + `{SKILL_DIR}/prompts/platform_forms.md`，逐 clip 按统一的标题风格写各平台文案，写入 `{UPLOAD_HOME}/物料/<节目>/<日期>/发布物料.json`。
- 🔒 `clip_num == 首条评论序号`（首评按编号直取）；播报标题/正文、`topic_tags`、头条标题这几个池子的顺序 ≠ clip 编号，必须按**新闻内容**匹配，不能按序号对齐。
- 核心数字只能取自播报正文，禁止编造。封面取该 clip 抽帧。
- 🔴 小红书 `xiaohongshu.标题` 写入前用 `len()` 自检 **≤20 字**（超长会让发布键失效）；视频号 `shipinhao.短标题` 自检 **≤16 字**且不含逗号、句号、百分号等特殊符号。
- 今日头条标题取值顺序：`toutiao.标题` → `xiaohongshu.标题` → `shipinhao.短标题`，不单独写也能兜底。

**STEP 3 先演练，再正式发**
```bash
python3 "{SKILL_DIR}/src/distribute_all.py" <节目> <日期> --no-publish
```
演练只填表不发布（YouTube 为 dry-run）。确认标题、封面、文案都对了，**经用户明确同意后**再正式发布：
```bash
python3 "{SKILL_DIR}/src/distribute_all.py" <节目> <日期>
```
- 内部顺序：抽封面 → 生成小红书手动包 → YouTube / 今日头条 / 视频号逐条上传 → 汇总 → 抓取视频号播放数据回流。
- 🔴 **日常分发不要加 `--platforms`**：默认已包含全部平台，手动缩小范围很容易让某个平台静默漏发。只补发某一条用 `--clips N`。
- **定时发表是默认行为**：视频号用平台自带的「定时发表」，把当天各条分散在 06:30–08:30 发出；上传完成后本机可关机，平台按时发布。自定义时段用 `--spread 07:00-12:00`，要立即发布用 `--no-spread`。所有时刻必须晚于当前时间，早于"现在+10分钟"的时刻会自动顺延。

**STEP 4 汇报与补发**
读 `distribute_all.py` 的汇总；某平台某条失败，单独补发：
```bash
python3 "{SKILL_DIR}/src/<平台脚本>" <节目> <日期> --clip N --publish
```

════════════════════════════════════
【小红书：只生成手动发布包】
════════════════════════════════════

本工具**不会**自动发布小红书。小红书明确限制脚本/自动化发布，作者主号曾因此被封 7 天。手动包在 `{UPLOAD_HOME}/物料/<节目>/<日期>/小红书手动包/`，内含各条视频、封面和一键复制用的 `发布清单.txt`，传到手机后在 App 里手动发布。

════════════════════════════════════
【合规提醒】
════════════════════════════════════

- **AI 生成内容标识**：按《人工智能生成合成内容标识办法》，画面、配音、文字任一环节由 AI 生成都需要标识。本工具**不会**自动勾选各平台的「AI 生成内容」声明，发布前请自行确认并勾选。
- 各平台对自动化发布的规则不同且会变化，使用前请自行阅读并遵守平台条款；因使用本工具导致的账号限制由使用者自行承担。

════════════════════════════════════
【平台机制备忘】
════════════════════════════════════

- **YouTube**：官方 API；竖屏即 Shorts；`--public` 公开发布，`--publish-at <RFC3339>` 定时；首条评论 API 无法置顶，需在 Studio 手动操作；播放列表按 `shows.json` 的 `youtube_playlist_id` 添加。
- **视频号**：表单位于 URL 含 `micro/content` 的 iframe 内；首次进入需关闭「我知道了」气泡；原创声明需在弹出的「原创权益」对话框中确认。**视频号「合集」有 500 条上限，满了会静默不收**——发布成功但合集里找不到时，去合集编辑页看「全部视频(N)」是否已到 500，满了就新建合集并更新 `shows.json` 的 `collection`。
- **今日头条**：竖屏视频不支持原创/赞赏/定时，各条之间会间隔几分钟上传，避免短时间内集中提交。
