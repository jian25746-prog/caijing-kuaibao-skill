# 标题家族风格（提炼自《头条图文》，2026-06-17 用户认可）

所有平台标题统一这一种"味道"，由 SKILL STEP 3 写文案时遵循。

## 公式
`[具体事实 + 数字]，[对普通人的影响 / 人物画面]`
- 结果先行、口语、第二人称代入（你 / 家里 / 手里有…的）
- 长度 ~16–20 字
- 数字必须真实（取自播报正文 / today_entries / 行情快照，**禁编造**）

## 验过的样本（直接当模板）
- 油价跌到三个月最低，**加油的钱要松一口气了**
- 金价银价一夜大涨，**家里有黄金的账面笑了**
- 比特币这周又跌了，**拿着的人开始睡不着**
- 制冷剂涨超30%，**今夏装空调的钱可能要多花**
- 散户押SpaceX一夜涨80%，**老交易员都看懵了**
- 马斯克一夜成万亿富翁，**美股科技股跟着嗨**（生成示例）

## 落地规则
1. **头条图文已有的**（民生向 2–3 条，用新闻身份**按内容**匹配到 clip）→ 标题直接用。
2. 其余 clip → 按上面公式**同风格生成**，保证一组里风格一致。

## 禁忌（沿用项目既有反馈）
- ❌ "揭晓式"戏剧化钩子（"你知道昨晚最可怕的名字是谁吗…"）——用户明确不喜欢。
- ❌ 编造摘要/正文里没有的具体数字。
- ❌ 标题与正文首句完全重复。

## 三平台标题派生（详见 platform_forms.md）
- **小红书 标题（≤20）**：公式标题直接用（必要时 +1 个 emoji）。
- **YouTube title（≤100）**：公式标题 + `｜7点财经快报 #Shorts`。
- **视频号 短标题（≤16）**：把公式标题**压到 ≤16**（如"油价跌破三个月低"）；**完整公式标题放进「描述」首句**当钩子。
